### 🚀 Production Systems & Architecture

* **[Individual Borrower Entity Resolution Pipeline](https://github.com/khush-dakwala/individual-borrower-resolution)**  
  A 4-pass asynchronous entity resolution pipeline utilizing SSA demographic databases, graph clustering, and dynamic fuzzy string normalization. Deployed with FastAPI and Streamlit to resolve discrepancies across multi-party borrower records.

* **[Corporate Borrower Entity Normalization Platform](https://github.com/khush-dakwala/corporate-entity-normalizer)**  
  An automated normalization platform leveraging a multi-factor scoring engine (shared token overlap, RapidFuzz orthographic metrics, and token cardinality) paired with legal suffix rules, cutting manual review volume to 5%.

* **[Institutional Lender Vector Classification Engine](https://github.com/khush-dakwala/lender-vector-matching)**  
  A high-throughput vector similarity search and classification pipeline combining Sentence-Transformers, FAISS indexing, and sparse matrix operations (`sparse-dot-topn`) to categorize and link financial entities across seven regulatory verticals.
